# Дачный помощник для мамы

Веб-приложение для телефона: что, когда и куда сажать на даче в Февральске (Амурская область).

**Адрес:** https://litvinovxd.github.io/dacha/

## Что сделать Роме (по порядку)

1. **Отправить маме ссылку** https://litvinovxd.github.io/dacha/ и попросить открыть её в Chrome — и с мобильного интернета, и с Wi-Fi. Это проверка, что сайт открывается в России (из Китая через VPN проверка не показательна).
2. **Поставить приложение маме на телефон** (раздел ниже).
3. **Положить ключи в секреты GitHub** и **подключить уведомления** (раздел «Уведомления о погоде»).
4. **Спросить маму** и прислать ответы Claude Code:
   - когда у вас обычно последний весенний и первый осенний заморозок (сейчас в календаре расчётные 25 мая и 10 сентября);
   - сколько ящиков рассады помещается на подоконник и какого размера;
   - сколько банок она закрывает (огурцы, томаты, икра, квашеная капуста) — от этого зависит число растений;
   - где в большом огороде в 2026 году росли капуста, морковь, лук, чеснок; что было в каждом парнике у теплицы;
   - сколько мешков картофеля нужно;
   - сколько обычно идёт посылка с семенами до Февральска (сейчас заложено 6 недель);
   - каких сортов из списка не надо и какие свои оставить (список — `VARIETIES.md`).
5. Перед тем как отдавать маме — **сделать дизайн** (каркас сейчас простой).

## Как поставить приложение маме на телефон

1. На телефоне открыть **Chrome** → адрес https://litvinovxd.github.io/dacha/
2. Меню **⋮** (три точки справа вверху) → **«Добавить на главный экран»** или **«Установить приложение»** → «Установить».
3. На экране появится значок с росточком «Дача». Дальше открывать только через него.
4. Один раз открыть приложение с интернетом — после этого оно работает и без интернета (кроме свежего прогноза погоды).
5. Отметки мамы («Сделано», дневник, покупки) хранятся в телефоне. Раз в 2 недели приложение напомнит отправить копию Роме: **Ещё → Дневник → Сохранить копию** → WhatsApp Роме. Если телефон потеряется или очистится — копию можно загрузить обратно там же («Восстановить из копии»).

## Как поменять сорт, срок или зону через Claude Code

Открыть папку проекта в VS Code с Claude Code и написать обычной фразой:

- «Замени сорт томата Верлиока на Благовест» — Claude проверит сорт в Госреестре (12-й регион) и в магазине мамы и обновит `data/varieties.json`;
- «Мама говорит, последний заморозок у нас около 5 июня» — поменяется опорная дата в `data/calendar.json`, весь календарь сдвинется;
- «Парник у теплицы 3 на самом деле 1,2 × 5 м» или «добавь грядку у бани» — поправится `data/zones_src.json`, схема пересчитается (`python scripts/zones.py`);
- «Добавь в покупки агроволокно 2 рулона к 1 мая» — `data/shopping.json`.

После изменений Claude сохраняет и отправляет их на GitHub — через 1–2 минуты новая версия на сайте, у мамы обновится при следующем открытии с интернетом.

## Что где лежит

| Папка / файл | Что там |
|---|---|
| `index.html` | Главная страница приложения |
| `css/` | Внешний вид (шрифты, цвета) |
| `js/` | Код приложения |
| `data/` | **Все данные** — код их только читает: `anketa` (ответы мамы), `climate` (климат), `crops` (культуры), `varieties` (сорта), `zones_src`/`zones` (участок), `rotation` (севооборот), `plan` (что куда на год), `calendar` (сроки), `cards` (как растить), `shopping` (покупки), `symptoms` (что с растением), `weather` (пороги погоды), `push` (публичный ключ уведомлений) |
| `CLIMATE.md`, `VARIETIES.md` | Отчёты по климату и сортам |
| `sw.js`, `manifest.webmanifest`, `img/` | Работа без интернета, установка значком, иконки |
| `.github/workflows/weather.yml` | Расписание вечерних уведомлений о погоде |
| `materials/` | Скриншоты участка |
| `scripts/` | Скрипты: анализ климата, отправка уведомлений о погоде |
| `PLAN.md` | Полный план проекта |

## Как обновлять данные

Проще всего — попросить Claude Code обычной фразой, например:

- «Замени сорт томата Санька на Белый налив»
- «Последний заморозок у нас обычно 5 июня, пересчитай календарь»
- «Переименуй зону "Большой огород, верх" в "Картофельное поле"»

Claude Code поменяет нужный файл в `data/`, сохранит изменения и выложит их на сайт.

### Календарь

Все сроки лежат в `data/calendar.json`. Они считаются от опорных дат: «высадка в теплицу 20 мая», «последний заморозок 25 мая» и т. д. Поменять опорную дату — и весь календарь сдвинется.

Чтобы посмотреть, что приложение покажет в другой день, добавьте к адресу `?date=2027-03-08`. Например: `https://litvinovxd.github.io/dacha/?date=2027-05-20`.

Допущения и непроверенные сроки помечены в файлах `data/` полем `"проверено": false`. Чтобы их посмотреть, достаточно спросить в чате Claude Code: «что ещё не проверено?».

### Планы посадки по местам

На странице каждого огорода, теплицы, парника и малины — кнопка **«🌱 План посадки»**: крупный план с грядками, рядами и каждым растением.

- Что куда и в каком порядке — `data/plan.json` → «2027» → место → «посадка».
- Расстояния между рядами и в ряду (с источниками) — `data/spacing.json`.
- После правок пересчитать: `python scripts/layouts.py` (или попросить Claude Code: «в верхнем огороде вместо гороха — фасоль»).

### Анкета

Файл `data/anketa.json` — ответы мамы о хозяйстве. Его можно заполнить и вручную: открыть файл, вписать ответ между кавычками `""`, сохранить. Пока поле пустое, приложение использует допущение и помечает это (видно только Роме).

## Уведомления о погоде

Каждый вечер в 19:00 (по Амурской области) GitHub сам смотрит прогноз. Если ночью заморозок, завтра жара, ливень или риск фитофторы — маме приходит одно уведомление. В спокойные дни — тишина. Пороги — в `data/weather.json`.

### Один раз: положить ключи в секреты GitHub

Ключи **никогда не кладутся в файлы проекта** — только в «Секреты» GitHub.

1. На компьютере в папке проекта откройте файл `vapid-keys.json` (его нет в GitHub, и так и должно быть).
2. Откройте https://github.com/litvinovxd/dacha/settings/secrets/actions → **New repository secret**.
3. Name: `VAPID_PUBLIC_KEY`, Secret: значение `publicKey` из файла (без кавычек) → **Add secret**.
4. Ещё раз **New repository secret**: Name `VAPID_PRIVATE_KEY`, Secret: значение `privateKey`.
5. Файл `vapid-keys.json` никому не пересылайте.

### Подключить мамин телефон

1. Мама открывает https://litvinovxd.github.io/dacha/ в **Chrome** → меню ⋮ → «Добавить на главный экран» (или «Установить приложение»).
2. В приложении: **Ещё → «Включить предупреждения о погоде»** → разрешить уведомления.
3. Появится код — мама жмёт **«Отправить в WhatsApp»** и отправляет его Роме.
4. Рома: **New repository secret**, Name `PUSH_SUBSCRIPTIONS`, Secret — этот код целиком.
   Если телефонов два (мама и Рома) — вставить оба кода, каждый на своей строке.
5. Проверка: https://github.com/litvinovxd/dacha/actions → «Погода» → **Run workflow** (галочка «проверочное» стоит) → Run. Через минуту на телефон должно прийти «Проверка: уведомления работают 👍».

### Если уведомления перестали приходить

- Откройте Actions → последний запуск «Погода». Если там написано «подписка устарела» — мама заново жмёт «Включить предупреждения», присылает новый код, Рома заменяет секрет `PUSH_SUBSCRIPTIONS` (кнопка Update).
- Если запусков давно нет — GitHub мог выключить расписание: Actions → «Погода» → **Enable workflow**. (Чтобы этого не случалось, скрипт раз в месяц сам делает маленький коммит.)
- Если запуск «зелёный», но уведомления нет — проверьте экономию батареи на телефоне (ниже).

### Экономия батареи на мамином телефоне

Android может «усыплять» Chrome, и уведомления теряются. Нужно разрешить Chrome работать в фоне. Пути отличаются по маркам:

- **Samsung:** Настройки → Приложения → Chrome → Батарея → «Не ограничено». И Настройки → Обслуживание устройства → Батарея → Ограничения фонового использования → убрать Chrome из «спящих».
- **Xiaomi / Redmi / POCO:** Настройки → Приложения → Chrome → Контроль активности (Батарея) → «Нет ограничений». Там же → Автозапуск → включить.
- **Huawei / Honor:** Настройки → Батарея → Запуск приложений → Chrome → выключить «Автоматическое управление», включить все три переключателя.
- **Другие:** Настройки → Приложения → Chrome → Батарея → «Без ограничений» / «Не оптимизировать».

И проверить: Настройки → Приложения → Chrome → Уведомления → включены; в самом Chrome: ⋮ → Настройки → Уведомления → сайт litvinovxd.github.io разрешён.

Если Web Push у мамы окажется ненадёжным — запасной вариант по плану: бот в мессенджере Max (если мама им пользуется). По сторонним статьям (октябрь 2026): бот создаётся через служебного бота @MasterBot в Max, API — `https://platform-api.max.ru`, токен передаётся в заголовке Authorization ([Habr](https://habr.com/ru/articles/1010332/), [vc.ru](https://vc.ru/telegram/2799410-sravnenie-max-bot-api-i-telegram-bot-api)). Официальную документацию (dev.max.ru) и условия создания ботов проверить, когда понадобится. Скрипт `scripts/notify.mjs` можно будет дополнить отправкой в Max — текст уведомления уже готов.
